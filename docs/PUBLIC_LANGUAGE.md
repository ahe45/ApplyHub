# 사용자 화면 언어

로그인, 회원가입, 비밀번호 재설정, 사용자 홈, 원서접수, 접수결과, 서류 제출, 수험표 조회 화면은 한국어와 영어를 지원합니다. 로그인 및 사용자 화면 상단의 `한국어 / English` 버튼으로 전환합니다. 관리자 화면은 한국어로 유지합니다.

선택한 언어는 현재 브라우저의 `applyhub.public-language`에 저장됩니다. 새로고침·페이지 이동 후에도 유지되며 같은 사이트의 다른 탭에도 적용됩니다. 저장소가 차단된 경우 현재 화면에서 전환할 수 있습니다. 전환 시 화면을 새로고침하거나 입력값을 초기화하지 않습니다.

## 구현과 번역 범위

- `client/app/public-messages.js`: 시스템 문구의 한국어 → 영어 사전. `{0}`, `{1}`은 데이터 치환값입니다.
- `client/app/public-i18n.js`: 사용자 화면의 텍스트·접근성 레이블·도움말을 갱신합니다. 원문을 노드별로 보관해 한국어로 복원하며, 화면이 다시 그려지거나 오류·타이머가 바뀌어도 적용됩니다.
- 로그인 화면에서는 `.common-login-stage` 내부만 처리하여 숨겨진 관리자 메뉴까지 번역하지 않습니다.
- 시스템에서 만든 조합 문구는 번역 목록에 전체 패턴을 추가합니다. 치환값에 포함된 사용자 데이터는 다시 번역하지 않습니다.
- 학교명, 공지사항, 약관, 선택지, 접수 답변, 파일명은 `translate="no"`로 구분합니다. 입력값, 선택지의 `value`, API 응답과 요청, DB 데이터는 자동 번역하지 않습니다.
- 공지사항 설정에서 로그인 전·후 공지 각각의 한국어/영어 캔버스를 나란히 표시합니다. 화면이 좁으면 세로로 배치합니다. 클릭하거나 키보드로 이동한 캔버스에 공통 서식 도구를 적용하며, 언어별 서식과 작성 중 내용은 독립적으로 유지하고 각 캔버스에서 저장합니다. 영어 공지가 없으면 기존 한국어 공지를 표시합니다. 사용자 언어 전환 시 공지의 미리보기와 펼친 내용이 함께 바뀝니다.
- 한국어 공지는 기존 설정 키를 유지하고 영어 공지는 `loginNoticeHtmlEn`/`applicantNoticeHtmlEn`으로 별도 저장합니다. 기존 공지나 DB 구조를 변경하지 않습니다.
- 전형 관리에서 전형·모집단위·전공의 한국어명과 영어명을 나란히 입력합니다. 영어명은 `admissionNameEn`/`unitNameEn`/`majorNameEn`으로 저장하며, 원서접수 선택 목록·선택 요약·접수결과에 반영합니다. 비어 있는 영어명은 한국어명을 표시합니다. 선택값과 기존 접수 답변은 한국어 원문을 유지합니다.
- 기존 전형 데이터에는 영어명 열을 빈 문자열 기본값으로 추가합니다. 전형 엑셀 양식과 내보내기에도 영어명 열을 포함하며, 영어 열이 없는 기존 양식을 업로드하면 저장된 영어명을 유지합니다. 영어 열을 제공하고 셀을 비우면 해당 영어명을 지웁니다.
- 가입·접수 설정에서 회원가입·원서접수·서류제출 질문의 한국어/영어 제목과 설명을 각각 입력합니다. 영어 모드에서 등록한 영어 문구를 사용하고, 비어 있는 영어 항목은 한국어로 표시합니다. 제목과 설명의 대체 표시는 각각 적용합니다.
- 회원가입 질문은 `labelEn`/`descriptionEn`, 원서접수·서류제출 질문은 `questionTextEn`/`questionDescriptionEn`으로 저장합니다. 기존 DB에는 영어 열을 빈 문자열 기본값으로 추가하여 기존 질문과 답변을 유지합니다.
- 직접 등록한 두 언어 문구는 `renderAuthoredText`가 이스케이프한 `data-i18n-ko`/`data-i18n-en`으로 표시하며 시스템 번역 사전을 거치지 않습니다. `data-i18n-aria-label-en`은 입력의 접근성 이름에도 등록한 영어를 적용합니다.
- 사용자 정의 접근성 레이블만 유지해야 하는 입력에는 `data-i18n-preserve="aria-label"`을 사용합니다. 시스템에서 제공하는 국가 목록은 기존 영문 국가명으로 표시합니다.
- 회원가입 국가 선택은 화면용 국가명만 바꾸고 제출할 국가 코드는 유지합니다. `data-i18n-display-value`가 붙은 읽기 전용 생년월일 표시는 영어에서 `YYYY-MM-DD`로 표시하며 저장된 생년월일은 유지합니다.
- 수험표 PDF 및 업로드한 문서는 작성된 원본을 표시합니다. 언어 변경은 문서 내용을 변환하지 않습니다.

새 화면이나 문구를 추가할 때는 번역 목록을 갱신하고, 직접 입력한 내용에 원문 표시 속성이 있는지 확인합니다. 브라우저 자동 번역이나 외부 번역 서비스는 사용하지 않습니다.

## 검증

`npm run test:public-language`는 별도 테스트 DB에서 실행됩니다. 한국어·영어 전환, 로그인 오류, 회원가입과 약관, 국가와 파일 선택, 접수 결과·서류·수험표, 입력·DB 값 보존, 관리자 화면 제외, 언어 유지, 탭 동기화, 저장소 차단, 모바일 가로 넘침을 검증합니다. 화면 이미지는 `.tmp-public-language-check/`에 저장합니다.
