전형 등록 업로드 전용 XLSX 양식을 내려받아 코드와 명칭 체계를 맞춘 뒤 업로드합니다.

선택된 데이터 파일이 없습니다. XLSX 파일을 이 영역으로 끌어다 놓아도 됩니다.
업로드 미리보기

XLSX 파일을 선택하면 실제 저장 전에 예상 신규/수정 건수를 전체 파일 기준으로 확인할 수 있습니다.

전형 등록 상세정보

언어를 선택해 전형·모집단위·전공 명칭을 입력합니다. 번역이 없으면 한국어명을 표시합니다.

공통 정보

언어별 명칭

선택한 언어의 명칭을 입력합니다. 번역을 비워 두면 한국어명이 표시됩니다.

전형 상세설정

전형별 적용 템플릿, 원서 수정, 수험번호 규칙과 운영 기간을 설정합니다.

선택한 0개 전형

입력한 기간을 선택 항목에 적용합니다. 비워 둔 기간은 해제되며, 혼합된 사용 여부는 스위치를 변경하지 않으면 유지됩니다.

적용 템플릿

가입·접수 설정에서 접수·서류 템플릿을, 수험표 양식 설정에서 수험표 양식을 만듭니다. 서류 제출 확인에도 같은 서류제출 템플릿이 적용됩니다.

수험번호 생성 규칙

전체 자리수와 코드·순번의 조합 순서를 설정합니다. 순번은 한 번만 포함하세요. 변경한 규칙은 새 접수에 적용됩니다.
